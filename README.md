# Biocode-project-

If you wish to run the comparison between human and e.coli, go to the file titled: main.py.

If you wish to run the comparison between Bacillus and e.coli, go to the file titled: test_bacillus_ecoli.py

If you wish to run the validation, go to the file titled: validation.py
If you wish to change the 3 PCs chosen, change the variables: pc_x, pc_y, pc_z, for any value from 1 to 50.
